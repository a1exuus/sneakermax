# SneakMax frontend patch

Патч для текущей ветки `dev`.

Исправляет frontend JS: мобильное меню, FAQ, фильтры каталога, quiz и формы.

Для карточки товара поддерживаются необязательные атрибуты:
`data-price`, `data-size`, `data-gender`.

GitHub-запись из этой сессии недоступна (403), поэтому файл нужно заменить вручную.
